# Player Fitness Management System
 
Java console application for managing player fitness data, generating training recommendations, and creating individual and team reports.
 
## 📌 About the Project
 
This application was originally developed as an academic project for an Intermediate Programming course.
 
The system allows users to register players and store physical information such as height, weight, body fat percentage, position, and player number.
 
Based on the player's body fat percentage, the application automatically assigns a recommended training category.
 
## ⚙️ Features
 
- Register multiple players.
- Store player information:
- Name
- Player number
- Position
- Height
- Weight
- Body fat percentage
- Automatically determine a recommended training category.
- Generate individual player reports.
- Generate team reports.
- Calculate average player height.
- Calculate average team body fat percentage.
- Validate user input.
- Display the current date and time.
- Handle invalid input using exception handling.
